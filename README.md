# Welcome to Frozen Bound Backport!
This mod backport all  the features from 26.3 and 26.4 drops to previous versions.

# Features:
### WildernessBound
- Dappled Forest
- Abandoned Camp
- Poplar woodset
- Shelf Mushroom
- Red Shrub
- Straw Bed
- Stats
- Wool and Concrete Sets
### Deep Freeze
- Ice Caves
- Snow,Calcite,Packed Ice sets
- Chiseled Soulslate
- Advancement
- Music Disc
- Icicles, Ice Crystals
- Frostbite
- Freezing Effect
- Jukebox Playlist
- More Features under Development
